# Cinematic Video Editor Portfolio

A premium, minimal portfolio website for a professional video editor built with React, Vite, and Bun. The experience is designed around a black-and-white luxury aesthetic, smooth motion, and polished interactions.

## Features
- Dual light/dark themes with persistent local storage preference
- Premium animated hero, section reveals, and motion-driven UI
- Portfolio section with filterable project cards
- Contact form with validation and toast notifications
- Responsive layout for desktop, tablet, and mobile
- SEO-ready structure with React Helmet

## Installation
```bash
bun install
```

## Development
```bash
bun run dev
```

## Production Build
```bash
bun run build
```

## Preview
```bash
bun run preview
```

## Deployment
The app is ready to deploy on Vercel, Netlify, Cloudflare Pages, or GitHub Pages.
